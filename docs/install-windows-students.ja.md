# Windows限定テスト手順

## 対象

この手順は、Directorから参加案内を受けた開発者・限定テスターだけが対象です。Windows版の正式公開手順ではありません。

## 未署名であること

今回のWindows MSIは未署名です。正式なWindows公開経路は準備中であり、GitHub Releaseの一般利用者向け配布物ではありません。

## 確認するSHA-256

Directorから、`TOMOS_AI-vX.X.X-windows-UNSIGNED-TEST-ONLY.msi` 形式のartifact名、SHA-256、MSIに隣接するnoticeを受け取ります。artifact名には `UNSIGNED` と `TEST-ONLY` が含まれ、noticeには `UNSIGNED` と `TEST ONLY` が明記されていることを確認します。ダウンロードしたファイル名、SHA-256、noticeがすべて一致した場合だけ、次へ進んでください。不足または不一致がある場合は実行せず、Directorへ報告してください。

PowerShellで確認する例:

```powershell
Get-FileHash -Algorithm SHA256 .\TOMOS_AI-vX.X.X-windows-UNSIGNED-TEST-ONLY.msi
```

## Windows警告

未署名のためWindowsの警告が表示され、発行元が表示されないことがあります。Windowsの保護機能を無効にしないでください。警告を常に無視しないでください。警告の種類と発行元の表示を結果報告へ記録してください。artifact名とSHA-256が一致しない場合は実行せず、Directorへ報告してください。

## インストール

artifact名とSHA-256の一致を確認できた場合だけ、MSIをダブルクリックして画面の案内に従います。インストール後は、デスクトップの `TOMOS AI Web UI` またはスタートメニューの `TOMOS AI > TOMOS AI Web UI` から起動します。

## 最初の質問

最初にTOMOS AIを開いたら、画面が開くことと、Ollamaが未導入の場合に日本語の案内が表示されることを確認してください。質問できる状態では、チャットに `こんにちは` と入力して送信し、エラーではなく応答が1回表示されることだけを確認します。質問と応答の会話本文は結果報告へ記録しません。モデル取得や企業サーバー接続は、テストの指示がない限り行いません。

## アンインストール

Windowsの「設定」から「アプリ」へ進み、`TOMOS AI` を選んでアンインストールします。Program Files内のファイルを手動で削除しないでください。

## データ保持確認

アンインストール前後で、既存の設定、Memory、Knowledge、教材パック、チャット履歴が意図せず削除されていないことを確認します。削除や不明な変化があれば、再インストールせずにDirectorへ報告してください。

## 結果報告

Directorへ、artifact名、隣接noticeの確認結果、確認したSHA-256、Windowsのバージョン、インストール結果、起動結果、警告の有無、アンインストール結果、データ保持確認の結果を報告してください。

成功・失敗にかかわらず、結果報告本文、ログ、すべての添付には、会話、Memory、Knowledge、秘密情報、個人名、フルパスを含めないでください。必要な情報に含まれる場合は、伏せ字にしてから報告します。スクリーンショットは警告画面など必要最小限にし、実行した操作を添えて報告します。

## 正式公開との違い

この限定テストは、未署名MSIの動作確認だけを目的としています。正式公開ではありません。一般利用者への配布、GitHub Releaseへの掲載、推奨案内は、Windows MSIの署名と正式公開承認が完了するまで行いません。
